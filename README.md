# 慢慢连 · 开心连连看与开心消消乐

两款适合在电脑上轻松游玩的离线游戏，共用大按钮、原创简笔画图案和声音设置，各自保存进度。**开心连连看**有 12 个计时配对关卡，**开心消消乐**有 20 个限步三消关卡，并支持自定义关卡。

## 直接开始玩

1. 使用较新版本的 Microsoft Edge 或 Google Chrome 打开 [`dist/index.html`](dist/index.html)。
2. 在首页选择“开心连连看”或“开心消消乐”，然后点击对应卡片上的“开始游戏”“继续游戏”或“选择关卡”。
3. 阅读关卡目标，点击“开始这一关”或“继续游戏”。

**只玩游戏不需要安装 Node.js，也不需要启动开发服务器。** 构建后的 HTML 已包含程序、样式和图案，可断网使用；分享游戏时只需复制这个文件。

注意：项目根目录的 `index.html` 是开发入口，不能代替 `dist/index.html` 作为离线成品直接使用。

## 开心连连看

- 依次点击两个相同图案，连线最多拐两次弯，不能穿过其他图块，可以绕棋盘外围连接。
- 所有关卡统一为 **10 行 × 14 列，共 140 张牌、70 对**，消除全部图案即可通关。
- 点错不扣生命，也不扣道具；时间用完或消除后出现死局会扣 1 生命。
- 每成功消除一对，最多补充 **3 秒**，但只补到本关初始时长；进度条已满就不再增加。最后一对也遵循相同规则。
- 消除及排列变化后，棋盘仍有图案但没有任何可连接的配对时，扣 1 生命；仍有生命就自动重新排列，生命用完则结束本局，不再重排。重排不扣提示或加时，初始发牌和清空棋盘不扣生命。
- 开局发牌和死局重排会在有限次随机排列中，优先挑选同类较分散的可玩棋盘，减少三连扎堆和直接相邻，仍保留简单配对的机会；不改变图案种类、牌数和空位。
- 根据关卡不同，消除后可能保持原位，或发生靠拢、分离及交替排列；这些移动自然形成的相邻配对不会被主动打散。

### 生命、道具与奖励

| 项目 | 规则 |
| --- | --- |
| 初始资源 | 5 生命、3 次提示、3 次加时 |
| 提示一下 | 标出一对可连接图案，成功提示消耗 1 次；提示显示期间不会重复扣次数 |
| 加时 | 每次增加 30 秒，消耗 1 次加时 |
| 消除奖励 | 每对最多补 3 秒，不消耗道具；仅补至本关初始时长，满格不再增加 |
| 通关奖励 | 生命 +1、提示 +2、加时 +1；最后一关同样发放 |
| 时间用完 | 扣 1 生命并暂停；仍有生命时，可手动补充 60 秒继续 |
| 棋盘死局 | 扣 1 生命；仍有生命就自动重排并继续，时间不重置，道具不扣减；生命用完则结束 |
| 生命用完 | 可重新挑战当前关，资源恢复为 5／3／3，保留已解锁关卡 |

生命和道具会带入下一关。刷新页面不会重复发放同一次通关奖励。

### 时间、暂停与退出

- 剩余时间以平滑缩短的进度条显示，旁边用小字标注剩余秒数。
- 不再常驻显示“每对 +3秒”；真实配对后短暂显示约 3 秒的奖励反馈，带轻柔放大缩小动画，进度条同步扫过一道亮光。开启减少动画时改为静态提示。
- 实际补足 3 秒显示“+3秒”，余量不足 3 秒只补至上限并显示“已补满”，已在上限则显示“时间已满”且不加时。
- 手动加时道具仍每次增加 30 秒。旧存档或道具带来的超额时间不会被扣减，但在降至本关初始时长以下前，配对不再增加时间。
- 点击“暂停休息”会停止倒计时并遮住棋盘；切换页面或窗口失焦时也会自动暂停，返回后需手动继续。
- 右上角提供“关闭游戏”；首页、关卡介绍、暂停及结算弹窗中也提供“退出游戏”。
- 退出前会暂停游戏并尝试保存正常进度，随后询问是否确定退出；保存失败时会明确提醒。

| 1 | 初次见面 | 18 | 6 分钟 | 保持原位 |
| 2 | 小小伙伴 | 19 | 5 分 45 秒 | 保持原位 |
| 3 | 落叶归根 | 20 | 5 分 30 秒 | 向下靠拢 |
| 4 | 轻轻上浮 | 21 | 5 分 20 秒 | 向上靠拢 |
| 5 | 上下分离 | 22 | 5 分 10 秒 | 上半部向上、下半部向下 |
| 6 | 左右分离 | 23 | 5 分钟 | 左半部向左、右半部向右 |
| 7 | 左右相依 | 24 | 4 分 50 秒 | 左右两半向中线聚拢 |
| 8 | 上下团圆 | 24 | 4 分 40 秒 | 上下两半向中线聚拢 |
| 9 | 花开两边 | 25 | 4 分 30 秒 | 上下分离、左右分离交替 |
| 10 | 四季流转 | 26 | 4 分 20 秒 | 上、右、下、左依次靠拢 |
| 11 | 聚散有时 | 27 | 4 分 10 秒 | 左右聚拢、左右分离、上下聚拢、上下分离循环 |

每次成功消除只执行一次排列变化，点错不会推进变化序列。

## 开心消消乐

- 依次点击两个相邻动物，或从一格短拖到邻格交换。键盘可以用方向键移动，按 Enter 或空格选择。
- 横向或纵向至少 3 个同类动物会消除。有效普通交换扣 1 步，整轮掉落和连锁不额外扣步。无效交换会换回，手动提示也不扣步。
- 每关累计积分，顶部用一条连续流动的三段进度条显示积分，三颗星嵌在进度条对应门槛位置，达到门槛后点亮；通关后按关卡设定的三个分数门槛获得星级，选关时保留显示最高星数。
- 完成全部目标即过关。目标可以是收集动物、清除障碍、触发指定特效或达到分数。最后一步也会先结算连锁和目标。步数用尽且目标未完成时，可免费重试。本游戏没有倒计时或生命限制。
- 20 个内置关卡中，前两关为 6 × 6，后续每个可见区域为 9 × 9，部分关卡带缺角、空洞或阶梯。长棋盘每清完一段会自动移到下一段，剩余步数和道具继续沿用。
- 每个内置关开局各有 2 次小锤子、自由交换和重排。锤子敲击一个格子，自由交换可跨绳交换相邻可移动动物，重排保留障碍和锁定位置。道具不扣步，礼盒可增加本关次数，重试后重置。

### 特效和障碍

横向四连生成纵扫，纵向四连生成横扫，L 或 T 形生成炸弹，直线五连生成魔力鸟。相邻特效可直接交换触发组合。直线与炸弹可以扩大清除范围，魔力鸟可以清同色、复制并引爆同色特效，双鸟会命中当前区域全部格子。全关目标完成后，场上未被冻结或覆盖的特效会按行优先自动连锁使用，新产生的特效也会继续结算，所有自动特效都会正常增加积分，最后才判定过关。自动结算有波次和特效预算，异常关卡达到上限时保留剩余特效并正常结束本关。

| 障碍 | 怎么处理 |
| --- | --- |
| 冰层 | 冻结动物，使其不能交换、下落或重排；消除格子上的动物或用小锤子逐层敲掉 |
| 雪块 | 在正交相邻格消除动物，或直接用特效、锤子逐层清除 |
| 绳子 | 普通交换无法跨绳，自由交换道具可以 |
| 藤蔓 | 底下的动物可参与匹配，但不能移动；特效单独命中会先解除覆盖 |
| 彩色礼盒 | 相邻同色动物消除、同色特效或锤击可打开，获得本关道具 |
| 传送门 | 动物下落时从入口转到有空位的出口 |
| 毒液 | 相邻消除、特效或锤击可清；普通回合没有清毒时可能扩张 |
| 灰毛球 | 覆盖会锁住动物，普通回合结束后可能跳到相邻动物上 |
| 水晶球 | 普通回合结束后按配置换色；相邻同色消除、特效或锤击可清除 |

### 自定义关卡

首页“关卡管理”可新建草稿、复制内置关、编辑棋盘和障碍、调整目标、星级分数门槛或分段，并独立试关。“发布到用户关卡”后可在消消乐选关中找到。支持导入单关、多个文件和整包 JSON，也可导出单关或已发布整包。界面会提示同标识冲突，导出的文件由浏览器下载。

关卡配置字段、合法示例、内置文件目录和构建流程见 [三消关卡编写说明](src/match3/levels/README.md)。

## 界面与音效

- 首页保留开始／继续、选择关卡等主要入口；关卡列表按需打开。
- 游戏操作集中在顶部，棋盘按窗口尺寸自适应完整显示，无需滚动寻找棋盘边缘。
- 棋盘显示蓝灰色虚线格线，消除后的空位仍保留格子；牌框适度加深，图案尺寸和可用连线路径不变，暂停时棋盘与格线一起隐藏。
- 操作按钮按用途区分：暖黄提示、绿色加时、蓝色暂停、紫色首页、红色退出；使用深色粗体文字和对应图标，并明确区分禁用状态，不仅靠颜色判断。
- 共有 **28 种原创 SVG 动物、水果和蔬菜图案**，首关使用 18 种，后续逐渐增加。
- 空间充足时显示图案名称；空间较小时优先保留图像面积，名称仍可通过悬停提示及无障碍标签获取。
- 支持键盘焦点和方向键移动；选中与提示不仅依靠颜色区分，并尊重系统的减少动画设置。
- 使用 Web Audio 合成点击、选中、消除、配对失败、提示、加时、暂停、恢复、超时、游戏结束、通关及低剩余时间提示音。
- 顶部可开关音效、调节音量和试听；没有背景音乐，也不需要下载音频文件。

音效通常在首次点击后启用。窗口越小或浏览器缩放越高，图块可用空间越少；推荐全屏游玩，必要时用 `Ctrl + 0` 恢复默认缩放。

两款游戏都可用顶部“暂停休息”遮住棋盘。窗口失焦、页面隐藏或返回首页时会暂停，回来后手动继续。浏览器通常要求先点击再允许全屏，游戏会在首次有效点击时补试，也可用顶部全屏按钮或 `F11`。如果浏览器禁止网页关闭当前标签页，可根据退出提示按 `Ctrl + W`。

## 自动保存

两款游戏通过浏览器 `localStorage` 各自保存棋盘、道具和解锁进度，共用音量与静音设置。

| 存储键 | 内容 |
| --- | --- |
| `slow-paws-link:save:v1` | 连连看当前局、生命、剩余时间、道具和解锁 |
| `slow-paws-link:sound:v1` | 两款游戏共用的音量与静音 |
| `slow-paws-match3:save:v1` | 消消乐当前局、关卡快照、剩余步数、目标、道具、已完成关卡和每关最高星级 |
| `slow-paws-match3:levels:v1` | 已发布或导入的消消乐自定义关卡 |
| `slow-paws-match3:editor:v1` | 消消乐编辑器草稿 |

进行中的局面刷新后以暂停状态恢复。消消乐旧局使用原关卡快照，重开才应用新版关卡。测试局和编辑器试关的行动与结算独立于正式存档。

- 刷新或重新打开后，进行中的游戏以暂停状态恢复，关闭期间不扣时间。
- 通关、超时和生命用完的状态也会保留，不能通过刷新绕过结算；死局扣生命与重排后的棋盘一并保存，刷新不会重复扣生命。死局耗尽生命时，即使还有剩余时间也不能继续，需重新挑战。
- “重新开始”会替换当前这一局并重置本轮资源，但保留已解锁关卡，操作前会提示确认。
- 较早版本的有效小棋盘存档会迁移到 10 × 14 棋盘，当前关重新排列，保留资源和解锁进度。已有 10 × 14 存档保留棋盘和剩余时间，不会因新版发牌策略或时限调整而重排或扣减。
- 已有 10 × 14 存档会保留原棋盘和剩余时间，不会因分散策略而重排，也不会因时限调整而扣减；新开的关卡使用新的发牌策略和时限。要立即体验新配置，可选择“重新开始”。

**存档不是云同步。** 更换浏览器、移动 HTML 文件、使用无痕模式或清除浏览器数据，都可能导致原存档不可用。本地文件的存储行为由浏览器决定；存储不可用时仍能游玩，但页面会提醒关闭后可能丢失进度。

## 测试／破解模式

在首页点击“测试／破解模式”，选择要测试的游戏，进入后展开顶部测试工具。

### 连连看测试

| 功能 | 说明 |
| --- | --- |
| 选择测试关卡 | 全部 12 关直接可选 |
| 冻结时间 | 默认开启，可关闭以测试正常倒计时 |
| 无限道具 | 默认开启，提示和加时不扣次数；不会赋予无限生命 |
| 消除一对 | 自动消除一对真实可连接图案，使用正常消除、排列及封顶加时流程；冻结时满格也不会继续加时 |
| 一键通关 | 直接触发通关结算，不额外发放跳过配对的时间奖励 |
| 立即超时 | 触发正常超时扣生命流程，即使时间冻结也可使用 |
| 退出测试 | 返回正常游戏的暂停状态；没有正常游戏时返回首页 |

### 消消乐测试

可选择所有内置或导入的关卡。无限步数和无限道具默认开启，可分别关闭。“自动走一步”执行一次真实合法交换和完整连锁。“重开本关”“一键通关”“立即失败”可验证重试和结算界面。测试进度只存放在内存，退出或刷新后会丢弃，也不会解锁正式关卡。

## 本地开发

### 环境

- 推荐 Node.js 22.12 或更高版本的受支持 LTS，以及 npm。
- 推荐较新的 Edge 或 Chrome；自动浏览器测试脚本使用本机安装的 Microsoft Edge。
- 首次安装开发依赖需要网络，构建后的游戏无需联网。

在项目根目录运行：

```bash
npm ci
npm run dev
```

按终端显示的本地地址打开游戏。默认使用 `http://127.0.0.1:5173/`；端口被占用时，普通开发启动可能自动改用其他端口。

### 构建离线成品

```bash
npm run build
```

构建会先执行 TypeScript 类型检查，再将脚本、样式和图案内联到 `dist/index.html`。修改源码后需要重新构建，离线文件才会更新。

如果需要通过本地服务器预览构建结果：

```bash
npm run preview
```

### 自动测试

```bash
npm test
```

单测覆盖连连看计时、连线、排列、死局和存档，也覆盖三消匹配、特效、障碍、关卡校验、编辑器和 20 个内置关卡的固定种子通关回放。

### 浏览器回归测试

先确保已安装 Microsoft Edge，并生成最新离线文件：

```bash
npm run build
```

在第一个终端启动固定端口的开发服务器：

```bash
npm run dev -- --port 5173 --strictPort
```

在第二个终端运行：

```bash
npm run test:browser
npm run test:match3
```

两条命令分别运行连连看和消消乐的无头 Edge 回归。连连看脚本覆盖：

- 固定测试盘的开局分散效果、完整首关、12 关切换与排列变化、生命／道具／奖励和测试模式隔离。
- 死局扣 1 生命后重排继续、最后生命耗尽结算、刷新不重复扣命及重新挑战。
- 时间进度条、消除奖励、加时、暂停、冻结与超时。
- 自动及手动全屏、拒绝全屏、退出取消、退出保存、标签页关闭受限提示和允许关闭的窗口。
- 音效、静音、音量、键盘操作、刷新恢复，以及存储或音频能力不可用的情况。
- 本地单 HTML 在断网环境下的玩法、音效与存档。
- 1280 × 720、1366 × 768、1920 × 1080 三种分辨率下，100%、125%、150%、200% 的 12 组等效缩放布局。

消消乐脚本覆盖正常游玩、20 关点击回放、九类障碍、操作与暂停、测试存档隔离、编辑器草稿与 JSON 流转，以及同样 12 组离线布局。

缩放测试通过 CSS 视口和设备像素比例模拟，不是直接操作浏览器菜单中的缩放设置。截图输出到 `artifacts/`；测试完成后可手动停止开发服务器。
